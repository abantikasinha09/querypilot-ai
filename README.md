🤖 QueryPilot AINatural Language to SQL Analytics AssistantQueryPilot AI is an AI-powered Text-to-SQL application that allows users to interact with a relational database using natural language.Instead of manually writing SQL queries, users can simply ask questions such as:"Which country has the most customers?"QueryPilot AI uses an LLM-powered agent to understand the question, inspect the database schema, generate SQL, execute the query, and return an understandable answer along with the generated SQL and query results.✨ Features💬 Natural Language Database QueriesAsk questions using everyday language instead of SQL.🤖 AI-Powered SQL GenerationUses a Groq-hosted LLM through LangChain to generate SQL queries.🔍 Generated SQL VisibilityView the SQL query generated by the AI.📊 Interactive Query ResultsResults are displayed in a structured table.📈 Automatic VisualizationSuitable query results are automatically converted into bar charts.🛡️ Read-Only SQL ValidationThe application validates generated SQL before its separate result-viewer execution.Destructive operations such as INSERT, UPDATE, DELETE, DROP, and ALTER are blocked by the application-level validation layer.🗄️ Database ExplorerExplore available tables and their columns directly from the interface.🕘 Query HistoryRecently executed questions and generated SQL queries are displayed during the current application session.⚙️ Technical DetailsView information about the model, framework, database, and SQL validation.🎨 Interactive Streamlit InterfaceClean browser-based interface designed for exploring databases through natural language.🧠 How It WorksQueryPilot AI follows an agent-based Text-to-SQL workflow.Plaintext                    ┌─────────────────────┐

It should not be considered a complete database security boundary for the agent's own tool execution. A production deployment should use a dedicated read-only database connection or database-level permissions.🚀 Getting Started1. Clone the repositoryBashgit clone https://github.com/abantikasinha09/querypilot-ai.git
cd querypilot-ai
2. Install dependenciesThis project uses uv for Python dependency management.Bashuv sync
3. Configure environment variablesCreate a .env file in the project root:Code snippetGROQ_API_KEY=your_groq_api_key
LANGCHAIN_TRACING_V2=false
LANGCHAIN_PROJECT=querypilot-ai
Never commit your .env file or expose your API key publicly.4. Run the command-line agentBashuv run python agent.py "How many customers are from Canada?"
5. Run the Streamlit applicationBashuv run streamlit run app.py
