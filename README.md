🤖 QueryPilot AI
Natural Language to SQL Analytics Assistant
QueryPilot AI is an AI-powered Text-to-SQL application that allows users to interact with a relational database using natural language.

Instead of manually writing SQL queries, users can simply ask questions such as:

"Which country has the most customers?"

QueryPilot AI uses an LLM-powered agent to understand the question, inspect the database schema, generate SQL, execute the query, and return an understandable answer along with the generated SQL and query results.

✨ Features
💬 Natural Language Database Queries

Ask questions using everyday language instead of SQL.

🤖 AI-Powered SQL Generation

Uses a Groq-hosted LLM through LangChain to generate SQL queries.

🔍 Generated SQL Visibility

View the SQL query generated by the AI.

📊 Interactive Query Results

Results are displayed in a structured table.

📈 Automatic Visualization

Suitable query results are automatically converted into bar charts.

🛡️ Read-Only SQL Validation

The application validates generated SQL before its separate result-viewer execution.

Destructive operations such as INSERT, UPDATE, DELETE, DROP, and ALTER are blocked by the application-level validation layer.

🗄️ Database Explorer

Explore available tables and their columns directly from the interface.

🕘 Query History

Recently executed questions and generated SQL queries are displayed during the current application session.

⚙️ Technical Details

View information about the model, framework, database, and SQL validation.

🎨 Interactive Streamlit Interface

Clean browser-based interface designed for exploring databases through natural language.

🔐 SQL Safety
QueryPilot AI includes an application-level validation layer for the SQL used by its result viewer.

Only read-oriented queries beginning with:

SELECT

WITH

are accepted by this validation layer.

Potentially destructive SQL operations such as:

INSERT

UPDATE

DELETE

DROP

ALTER

CREATE

TRUNCATE

are rejected.

Important: This validation layer protects the application's separate result-viewer execution. It should not be considered a complete database security boundary for the agent's own tool execution. A production deployment should use a dedicated read-only database connection or database-level permissions.

🚀 Getting Started
1. Clone the repository
Bash
git clone https://github.com/abantikasinha09/querypilot-ai.git
cd querypilot-ai
2. Install dependencies
This project uses uv for Python dependency management.

Bash
uv sync
3. Configure environment variables
Create a .env file in the project root:

Code snippet
GROQ_API_KEY=your_groq_api_key
LANGCHAIN_TRACING_V2=false
LANGCHAIN_PROJECT=querypilot-ai
Never commit your .env file or expose your API key publicly.

4. Run the command-line agent
Bash
uv run python agent.py "How many customers are from Canada?"
5. Run the Streamlit application
Bash
uv run streamlit run app.py
The application will open in your browser.

🔄 Query Processing Flow
A typical request follows this process:

User enters a natural-language question

QueryPilot AI receives the question

Agent inspects available database tables

Agent inspects relevant table schemas

Groq LLM generates SQL

SQL query is executed

Query results are returned

QueryPilot AI generates a natural-language answer

Results and SQL are displayed in Streamlit

Suitable results can be visualized as a chart

📌 Project Goals
The project demonstrates how modern LLM-based agents can be combined with traditional relational databases to create a natural-language analytics interface.

The main goals are:

Convert natural language into SQL.

Allow users without SQL knowledge to explore databases.

Demonstrate agent-based database interaction.

Make generated SQL visible and understandable.

Present database results in an accessible interface.

Explore safe handling of read-only analytical queries.
