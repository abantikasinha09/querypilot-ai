# 🤖 QueryPilot AI

### Natural Language to SQL Analytics Assistant

QueryPilot AI is an AI-powered Text-to-SQL application that allows users to interact with a relational database using natural language.

Instead of manually writing SQL queries, users can simply ask questions such as:

> "Which country has the most customers?"

QueryPilot AI uses an LLM-powered agent to understand the question, inspect the database schema, generate SQL, execute the query, and return an understandable answer along with the generated SQL and query results.

---

## ✨ Features

- 💬 **Natural Language Database Queries**
  - Ask questions using everyday language instead of SQL.

- 🤖 **AI-Powered SQL Generation**
  - Uses a Groq-hosted LLM through LangChain to generate SQL queries.

- 🔍 **Generated SQL Visibility**
  - View the SQL query generated by the AI.

- 📊 **Interactive Query Results**
  - Results are displayed in a structured table.

- 📈 **Automatic Visualization**
  - Suitable query results are automatically converted into bar charts.

- 🛡️ **Read-Only SQL Validation**
  - The application validates generated SQL before its separate result-viewer execution.
  - Destructive operations such as `INSERT`, `UPDATE`, `DELETE`, `DROP`, and `ALTER` are blocked by the application-level validation layer.

- 🗄️ **Database Explorer**
  - Explore available tables and their columns directly from the interface.

- 🕘 **Query History**
  - Recently executed questions and generated SQL queries are displayed during the current application session.

- ⚙️ **Technical Details**
  - View information about the model, framework, database, and SQL validation.

- 🎨 **Interactive Streamlit Interface**
  - Clean browser-based interface designed for exploring databases through natural language.

# 🧠 How It Works

QueryPilot AI follows an agent-based Text-to-SQL workflow.

```text
                    ┌─────────────────────┐
                    │      User Question  │
                    │  "Who bought most?" │
                    └──────────┬──────────┘
                               │
                               ▼
                    ┌─────────────────────┐
                    │    QueryPilot AI    │
                    │    LangChain Agent  │
                    └──────────┬──────────┘
                               │
                               ▼
                    ┌─────────────────────┐
                    │    Database Tools   │
                    │                     │
                    │ • List Tables       │
                    │ • Inspect Schema    │
                    │ • Execute SQL       │
                    └──────────┬──────────┘
                               │
                               ▼
                    ┌─────────────────────┐
                    │     Groq LLM        │
                    │ openai/gpt-oss-120b │
                    └──────────┬──────────┘
                               │
                               ▼
                    ┌─────────────────────┐
                    │    SQL Query        │
                    │                     │
                    │ SELECT ...          │
                    └──────────┬──────────┘
                               │
                               ▼
                    ┌─────────────────────┐
                    │   SQLite Database   │

                               │
                               ▼
                    ┌─────────────────────┐
